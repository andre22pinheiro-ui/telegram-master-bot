# 🏡 Telegram Master Bot (@AndrePinheirobot)

Bot Telegram pessoal e familiar 100% Cloud-Native (Render 24/7 + SQLite WAL + Google Drive Write-Through + Cascata de IA com temperatura 0.0).

## 🌟 Funcionalidades Principais

- 🥗 **Nutrição & Alta Performance**: Meta diária de 160g de proteína, 2.5L de água, 5g de creatina e motor de receitas saudáveis (Airfryer e Monsieur Cuisine Connect sem refogados pesados).
- 🏷️ **Catálogo de Produtos & Rótulos**: Registo de tabela nutricional oficial por 100g/100ml com separação canónica face ao consumo diário.
- 🛒 **Gestão de Compras & Despensa**: Lista de compras e histórico de compras sem impacto no balanço calórico do dia.
- 📡 **Radar de Oportunidades 5 Frentes**: Vigilância de Imobiliário (CMVM), Carros, Tech, Amazon.es (Omnibus 90 dias) e Apple (Poupança Grau A vs Novo 3 anos de garantia).
- 📰 **Notícias Oficiais Certificadas**: Fontes verificadas da ERC, Governo de Portugal, Diário da República, IPMA e CM Amarante.
- 🏡 **Família & Produtividade**: Gestão de tarefas, notas, rotinas familiares e lembretes com fuso horário `Europe/Lisbon`.
- ☁️ **DevOps & Engenharia Cloud**: Monitorização da infraestrutura Render, Vercel e compilações de APK via GitHub Actions sem dependência de PC local.
- 🔒 **Isolamento Estrito**: Gestão operacional de pesados, rotas e tacógrafo reside exclusivamente no bot dedicado `@zeropaperfrotaBot`.

## 🚀 Como Iniciar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Executar testes determinísticos (bateria mestre)
node tests/run_master_battery.mjs

# 3. Iniciar o bot em modo de desenvolvimento
npm run dev
```
