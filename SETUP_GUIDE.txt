PARTE 1 — CONFIGURAÇÃO DO BOT NO @BOTFATHER (Telegram)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Abre o Telegram e procura por @BotFather
2. Envia o comando: /newbot
3. Escolhe um nome para o bot (ex: "André Assistente")
4. Escolhe um username único (ex: "andrePinheirobot")
5. O BotFather devolve o TOKEN — guarda-o!
   Ex: 9048099830:AAHKIWqN36KTnePUcqk-LaMq7pJGBukCDTU

COMANDOS ÚTEIS NO BOTFATHER:
  /setcommands — Definir atalhos de comandos visíveis no bot
  /setdescription — Descrição do bot
  /setabouttext — Texto "Sobre"
  /setuserpic — Foto de perfil do bot

COMANDOS SUGERIDOS (copia e cola no /setcommands):
  start - Iniciar o assistente
  ajuda - Ver todos os comandos
  projetos - Listar repositórios GitHub
  criar_app - Criar novo repositório
  rota - Calcular rota de pesados
  tacografo - Verificar limites de tacógrafo
  avaliacao - Avaliar imóvel por m²
  compras - Lista de compras
  nota - Guardar nota
  tarefa - Adicionar tarefa
  briefing - Resumo do dia

PARTE 3 — CONFIGURAÇÃO DO FICHEIRO .env
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Edita o ficheiro .env na raiz do projeto:

  TELEGRAM_BOT_TOKEN_MASTER=<token do BotFather>
  CHAT_ID_AUTORIZADO=950415577

Variáveis opcionais (ativam funcionalidades extra):

  GEMINI_API_KEY=<chave da Google AI Studio>
    → Necessária para: análise imobiliária, assistente dev, briefings inteligentes
    → Obter em: https://aistudio.google.com/app/apikey

  ORS_API_KEY=<chave do OpenRouteService>
    → Necessária para: calcular rotas de pesados (/rota)
    → Obter em: https://openrouteservice.org/dev/#/signup (gratuito)

  GITHUB_TOKEN=<Personal Access Token do GitHub>
    → Necessário para: listar e criar repositórios (/projetos, /criar_app)
    → Obter em: GitHub → Settings → Developer Settings → Personal Access Tokens
    → Permissões necessárias: repo (full access)

  VERCEL_TOKEN=<token de deploy>
    → Necessário para: deploy automático via Vercel (funcionalidade futura)
    → Obter em: https://vercel.com/account/tokens

PARTE 5 — PRODUÇÃO COM PM2 (Execução Contínua)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PM2 garante que o bot reinicia automaticamente se crashar.

Iniciar com PM2:
  pm2 start ecosystem.config.cjs

Verificar estado:
  pm2 status

Ver logs em tempo real:
  pm2 logs telegram-master-bot

Reiniciar:
  pm2 restart telegram-master-bot

Parar:
  pm2 stop telegram-master-bot

Guardar configuração para arranque automático com Windows:
  pm2 save
  pm2 startup

IMPORTANTE — Arranque automático no Windows:
  Após "pm2 startup", o PM2 indica o comando exato a executar.
  Copia e executa esse comando como Administrador.
  Depois executa: pm2 save
  O PM2 reinicia agora automaticamente quando o Windows arranca.

PARTE 6 — DEPLOY NA NUVEM (Render.com — Gratuito)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Para correr 24/7 sem depender do teu PC:

  1. Faz push do projeto para o GitHub:
     git init
     git add .
     git commit -m "first commit"
     git remote add origin https://github.com/SEU_USER/telegram-master-bot.git
     git push -u origin main

  2. Vai a https://render.com e cria conta
  3. Clica em "New" → "Web Service"
  4. Liga o repositório GitHub
  5. Configurações:
     - Runtime: Node
     - Build Command: npm install
     - Start Command: node index.js
  6. Em "Environment Variables", adiciona todas as variáveis do .env
  7. Clica Deploy

  NOTA: O plano gratuito do Render.com hiberna após 15min de inatividade.
  Usa o UptimeRobot para manter o bot sempre ativo:
  → https://uptimerobot.com (monitor HTTP a cada 5min)
  
  IMPORTANTE: Em modo polling (como está configurado), o bot não precisa de
  webhook — funciona diretamente com Render mesmo no plano gratuito.

ERRO: "TELEGRAM_BOT_TOKEN_MASTER não definido"
  → Verifica se o ficheiro .env existe e tem o token correto

ERRO: "409 Conflict: terminated by other getUpdates request"
  → Tens o bot a correr em dois lugares ao mesmo tempo
  → Para uma das instâncias (pm2 stop ou Ctrl+C no terminal)

ERRO: "Cannot find module"
  → Certifica-te que fizeste "npm install" no diretório do projeto
  → Verifica que estás no diretório correto (cd telegram-master-bot)

ERRO: "403 Forbidden: bot was blocked by the user"
  → O utilizador bloqueou o bot — vai ao Telegram e desbloqueia

ERRO ORS: "403 Forbidden"
  → O ORS_API_KEY está inválido ou expirado
  → Renova em https://openrouteservice.org

BOT NÃO RESPONDE:
  → Verifica pm2 status (deve mostrar "online")
  → Verifica pm2 logs para erros
  → Confirma que o CHAT_ID_AUTORIZADO é o correto
